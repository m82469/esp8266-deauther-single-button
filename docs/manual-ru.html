Только для авторизованного тестирования. Эта прошивка отправляет кадры деаутентификации и beacon‑фреймы — это техника отказа в обслуживании (DoS) против сетей 802.11. Используйте её только против собственных сетей и устройств либо с письменным разрешением владельца, и заранее проверьте требования законодательства вашей страны к радиопередаче на 2.4 ГГц.

Экспериментальная прошивка поверх SDK ESP8266, не предназначенного для этой задачи — возможны баги.

RF · TX
01 · Первое включение

Быстрый старт

  1. 1
    Подайте питаниеПодключите по USB. OLED 0.96″ покажет заставку, затем перейдёт в главное меню — см. §02.
  2. 2
    Подключитесь к точке настройкиСеть Wi‑Fi pwned, пароль deauther, адрес 192.168.4.1 в браузере. Смените оба значения в §05 прежде чем делать что‑либо ещё — это заводские настройки, известные всем.
  3. 3
    Или без экрана — через serialОткройте монитор порта на COM3, 115200 бод, и введите help. Каждому пункту экранного меню в этом справочнике соответствует команда из §06.
  4. 4
    Навигация по экрануТап листает пункты меню, удержание (≥800 мс) открывает выбранный — на этой плате всего одна кнопка, полная схема жестов в §03.

На этой сборке в SPIFFS уже лежит autostart.txt, который при каждой загрузке сам запускает демонстрационное сканирование точек и клиентов — это штатное поведение прошивки DSTIKE, не баг.

02 · Экранное меню

Карта меню

То, что реально показывает OLED, восстановлено из DisplayUI.cpp. Зелёные ветки только читают состояние; медная — передаёт в эфир.

03 · Физическое управление

Одна кнопка, два жеста

Штатная прошивка Deauther рассчитана на четыре кнопки (UP/DOWN/A/B). На этой плате кнопка одна — FLASH на GPIO0, — поэтому в DisplayUI.cpp навигацию и выбор свели к одному жесту тап/удержание вместо перепайки платы.

TAP
Следующий пунктДвигает выделение по текущему списку по кругу — то, что раньше делали UP/DOWN.
HOLD
Выбор (≥800 мс)Открывает выделенный пункт — то, что раньше делала A. Долистайте до пункта [BACK] в конце списка и удержите — выход на уровень выше тем же жестом.

Компромисс: при одной паре жестов не осталось свободного жеста под старые контекстные действия кнопки A (долгое нажатие для переименования/удаления записи в Select) — они с экрана недоступны, используйте вместо них команды set name / remove из §06.

Scan — Сканирование

Пассивно · только слушает

Проходит по каналам 2.4 ГГц в поисках точек доступа и/или клиентских устройств (станций), с ними связанных. Результаты питают все остальные разделы — цели выбираются здесь до запуска Select или Attack.

БезопасноТолько приём эфира, плата ничего не передаёт — на окружающих повлиять не может в принципе.
// эквиваленты в serial
scan aps -t 15
scan stations -ch 6
scan wifi -t 0

Select — Выбор (на экране SELECT, команда в serial — show)

Пассивно · просмотр результатов

Список того, что нашло последнее сканирование — точки доступа, станции, сохранённые имена устройств, сохранённые SSID. Удержание на пункте — выбрать/снять выбор.

БезопасноПросмотр уже собранных данных на самом устройстве — ничего не передаётся в эфир.
// эквиваленты в serial
show aps
select ap 2
remove ap 2

Attack — Атака

Передаёт в эфир · нужна авторизация

Включите Deauth, Beacon и/или Probe, затем START. Deauth отключает выбранные станции от их точки доступа; Beacon/Probe анонсируют поддельные SSID из вашего списка, сбивая с толку сканеры поблизости. Одновременно работает только Deauth либо Deauth‑all.

ОпасноРеальная передача 802.11-кадров: заденет любую сеть/устройство в радиусе действия на выбранном канале, не только ваши. Запускать только когда точно известно, что чужих сетей рядом нет.
// эквиваленты в serial
attack deauth -t 60
attack beacon probe
stop attack

Packet Monitor — Монитор пакетов

Пассивно · проверка результата

Живой столбчатый график пакетов в секунду на активном канале, пока идёт scan wifi. Способ убедиться, что атака действительно работает, без ноутбука и Wireshark под рукой.

БезопасноТоже только приём — график считает чужие пакеты, но плата сама ничего не шлёт.
// эквиваленты в serial
scan wifi -ch 6
draw 25 2

Clock — Часы

Косметика

Превращает OLED в обычные цифровые часы — два экрана, «Показать» и «Установить время». В основном используется, чтобы устройство выглядело безобидно, пока лежит на столе между тестами.

БезопасноЧистая косметика, радио вообще не задействовано.
// без serial-эквивалента — только экран

LED — Индикатор

Статусный индикатор

Управляет встроенным RGB‑светодиодом (если он есть) — цвет меняется автоматически при сканировании или атаке, либо задаётся вручную с отключением автообновления.

БезопасноПросто цвет светодиода, на эфир не влияет.
// эквиваленты в serial
led #ff2d00 200
set ledEnabled false

Random Routers — Случайные роутеры

Select → SSIDs → RANDOM ROUTERS · передаёт сразу

Наш собственный пункт (его нет в оригинальной прошивке). Одним нажатием: генерирует 80 имён в стиле заводских названий роутеров (TP-Link_4F2A, Keenetic_C019 и т.п.) и сразу запускает Beacon-атаку с ними — отдельно заходить в Attack не нужно, экран сам переключится туда и покажет счётчик пакетов.

ОпасноС этой правкой пункт больше не «просто список» — он реально передаёт ~500 beacon-кадров/сек в эфир, как только вы его открыли. Все устройства в радиусе действия увидят все 80 сетей в своих WiFi-сканерах. Подключиться к ним по‑прежнему нельзя (это не настоящие точки доступа, ввести пароль некуда), но сам факт передачи — это уже как в разделе Attack: только когда точно известно, что рядом нет чужих сетей и устройств.
// путь в меню / serial
Select → SSIDs → RANDOM ROUTERS (удержание)
add ssid routers 80
attack beacon

06 · Serial-консоль

Справочник команд

115200 бод на COM3. Команда help на самом устройстве покажет живой список — здесь те же команды сгруппированы по назначению.

Разведка

scan [aps/stations/wifi] [-t с] [-ch n]
Запустить сканирование; режим "wifi" также питает монитор пакетов.
show [selected] [aps/stations/names/ssids]
Показать результаты сканирования или сохранённые списки.
select / deselect [тип] [id]
Отметить цели для следующей атаки.

Списки целей

add ssid <имя> [-wpa2] [-cl n]
Добавить поддельный SSID в очередь beacon/probe.
add name <имя> -ap/-st <id>
Сохранить найденное устройство под понятным именем.
remove <ap/station/name/ssid> <id>
Удалить одну запись или все записи типа.

Атака и одиночные кадры

attack [deauth/deauthall/beacon/probe] [-t с]
Запустить включённые типы атаки.
attack status [on/off]
Пакеты в секунду в реальном времени во время атаки.
send deauth/beacon/probe …
Отправить один вручную собранный кадр.
stop [scan/attack]
Остановить то, что выполняется.

Файлы (SPIFFS)

load / save [ssids/names/settings] [файл]
Сохранить состояние на флеш.
print / delete / replace <файл>
Редактировать строки файла из консоли.
format
Полностью очистить файловую систему.

Система

sysinfo
ОЗУ, канал, MAC-адреса, использование SPIFFS.
get / set <настройка> <значение>
Прочитать или изменить любую настройку из §05.
reboot / reset
Жёсткая перезагрузка либо сброс настроек по умолчанию.

Автоматизация и разное

run <файл> [-c с]
Повторить сохранённый скрипт, при желании по циклу.
write <файл> <команда>
Добавить одну команду в файл-скрипт.
screen mode <menu/packetmonitor>
Принудительно переключить текущий экран OLED.
